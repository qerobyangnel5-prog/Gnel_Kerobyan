# Լաբորատոր աշխատանք 2 – RLE սեղմում

Դասընթաց՝ Ծրագրային ապահովման անվտանգություն

## Նպատակ

Այս լաբորատոր աշխատանքի նպատակն է ուսումնասիրել **Run-Length Encoding (RLE)** սեղմման ալգորիթմը և իրականացնել այն ծրագրային տեսքով։

## Նկարագրություն

Run-Length Encoding (RLE)-ը տվյալների սեղմման պարզ մեթոդ է, որը փոխարինում է նույնական սիմվոլների հաջորդականությունը մեկ սիմվոլով և դրա կրկնությունների քանակով։

## Ծրագրի հնարավորությունները

Ծրագիրը կատարում է հետևյալ գործողությունները․

* Տողի սեղմում RLE ալգորիթմով
* Սեղմված տվյալների վերականգնում (decompression)
* Սկզբնական, սեղմված և վերականգնված տեքստի ցուցադրում

## Ալգորիթմի գաղափարը

1. Կարդալ մուտքային տողը
2. Հաշվել նույն սիմվոլների հաջորդականության քանակը
3. Գրանցել քանակը և սիմվոլը միասին
4. Արտածել սեղմված տողը

## Եզրակացություն

Run-Length Encoding ալգորիթմը տվյալների սեղմման պարզ և արդյունավետ մեթոդ է այն դեպքերում, երբ տվյալների մեջ կան շատ կրկնվող սիմվոլներ։
Այս լաբորատոր աշխատանքի ընթացքում իրականացվեց RLE ալգորիթմի ծրագրային իրականացում և ուսումնասիրվեց դրա աշխատանքային սկզբունքը։
